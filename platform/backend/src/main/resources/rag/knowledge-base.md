# BankBridge 대행기관 업무 종합 백과사전 (RAG 지식베이스)

본 문서는 대행기관(우체국 등) 직원이 은행 업무를 수행하며 고객의 모든 질문에 전문적으로 대응할 수 있도록 비즈니스 로직, 보안 기술, 금융 법규, 장애 대응을 총망라한 종합 가이드입니다.

---

## 1. 고객 정보 보호 안내
- **중계 플랫폼은 고객 정보를 열람할 수 없습니다.** 입력된 정보는 암호화된 채로 전달되며, 중간 서버에서는 내용을 볼 수 없습니다.
- **고객 정보는 오직 은행만 확인합니다.** 대행기관을 포함한 중계 경로 어디에도 원본 데이터가 저장되지 않습니다.
- **계좌번호 조회 시 원본이 노출되지 않습니다.** 혹시 정보 유출 사고가 발생하더라도 실제 계좌번호를 알아낼 수 없는 구조입니다. 고객이 보안을 우려할 경우 이 점을 안내하십시오.

---

## 2. 대출 심사 상세 가이드 (Loan Underwriting)

### 2.1. 심사 상태(Status)별 응대
- **PENDING (심사 중):** 5초 간격으로 상태를 확인(Polling)합니다. "네트워크 및 심사 시스템 확인 중입니다. 잠시만 기다려 주십시오"라고 안내하십시오.
- **APPROVED (승인):** 최종 승인 한도와 금리가 확정된 상태입니다.
- **REJECTED (거절):** 거절 사유(신용미달, DSR 초과 등)를 확인하여 안내하십시오.

### 2.2. 거절 사유별 상세 설명 (Cut-off)
- **신용점수(NICE):** 600점 미만은 즉시 거절됩니다. 800점 이상은 저금리, 600~800점은 중금리 상품이 추천됩니다.
- **DSR (총부채원리금상환비율):** 모든 대출 원리금 합계가 연소득의 40% 초과 시 거절됩니다. "소득 대비 부채 비율이 규정을 초과했습니다"라고 안내하십시오.
- **법정 최고금리:** 가산금리 포함 최종 금리가 연 20%를 초과하면 대출이 불가능합니다.

## 3. 대출 상품 및 상환 방식 (Loan Products)

### 3.1. 상환 방식별 장단점 비교
| 방식 | 특징 | 장점 | 단점 |
| :--- | :--- | :--- | :--- |
| **원리금 균등** | 매월 내는 [원금+이자] 합계가 동일 | 매달 지출 계획이 일정함 | 초기 이자 부담이 큼 |
| **원금 균등** | 매월 내는 [원금]이 동일 | 대출 잔액이 빨리 줄어 총 이자가 가장 적음 | 초기 상환 부담이 가장 큼 |
| **만기 일시** | 기간 중 이자만 내고 만기에 원금 전액 상환 | 매월 상환 부담이 가장 적음 | 총 이자 부담이 가장 큼 |

### 3.2. 거치 기간 (Grace Period)
- 원금을 갚지 않고 이자만 내는 기간입니다. 거치 기간 종료 후에는 원금 상환이 시작되어 부담이 급증하므로 고객에게 반드시 확인시켜야 합니다.

---

## 4. 고객 부담 비용 및 수수료 (Costs & Fees)

### 4.1. 중도상환해약금 (Redemption Fee)
- **부과 기간:** 대출 실행 후 3년 이내 상환 시.
- **면제 조건:** 3년 경과 후, 만기 3개월 미만 남은 경우, 한도대출(마이너스 통장).
- **요율:** 최대 1.4% 내에서 잔여 일수에 비례하여 차등 적용.

### 4.2. 인지세 (Stamp Duty)
- **5천만 원 이하:** 면제
- **5천만 원 ~ 1억 원:** 7만 원 (고객 3.5만 원 / 은행 3.5만 원)
- **1억 원 ~ 10억 원:** 15만 원 (고객 7.5만 원 / 은행 7.5만 원)
- **10억 원 초과:** 35만 원 (고객 17.5만 원 / 은행 17.5만 원)

### 4.3. 기타 부대비용
- **근저당 설정:** 등기신청수수료, 법무사 수수료 등은 은행이 부담합니다.
- **감액/말소 등기:** 대출 상환에 따른 등기 비용은 고객이 부담합니다.

## 5. 금융소비자 권리 보호 (Consumer Rights)

### 5.1. 청약철회권 (14일 이내)
- 대출 실행 후 14일 이내에 계약 철회 가능.
- 고객이 부담한 인지세 등 제세공과금은 반환되지 않으며, 은행이 대납한 비용은 고객이 갚아야 합니다.

### 5.2. 고령층(65세 이상) 보호 정책
- **우선 설명:** 불이익 사항(연체이자, 기한의 이익 상실 등)을 다른 정보보다 우선적으로 설명해야 합니다.
- **이해 확인:** 설명을 충분히 이해했는지 자필 서명 또는 녹취로 반드시 확인하십시오.

## 6. 창구 응대 Troubleshooting (FAQ)

### 6.1. 상황별 대응 매뉴얼
- **Q: 계좌 비밀번호를 잊어버렸어요.**
  - **A:** 대행기관에서는 비밀번호 초기화가 불가능합니다. 신분증 지참 후 은행 영업점을 방문하셔야 합니다.
- **Q: 서류를 잘못 올렸어요.**
  - **A:** '서류 제출' 단계에서 해당 파일을 삭제하고 다시 업로드할 수 있습니다. 이미 심사가 진행 중이면 심사 취소 후 재신청해야 합니다.
- **Q: 금리가 너무 높아요.**
  - **A:** '금리인하요구권'을 안내하십시오. 취업, 승진 등으로 신용이 좋아지면 추후 인하를 요청할 수 있습니다.

### 6.2. 필수 구비 서류 목록
1. **본인 확인:** 신분증 (주민등록증, 운전면허증 등)
2. **심사 서류:** 신용정보조회 동의서, 소득확인 서류, 재직증명서(필요 시)
3. **계약 서류:** 대출거래약정서, 상품설명서, 근저당설정계약서(담보 시)

## 8. 오류 이체 처리 매뉴얼

### 8.1. 상황별 처리 절차

#### Case A. 당행 → 당행 오류 이체 (같은 은행 내)
**처리 가능 여부:** 수취인 동의 없이도 당행 내부 조치 가능 (단, 법적 절차 필요)

1. **즉시 조치:** 고객에게 이체 일시·금액·오류 계좌번호를 서면으로 확인받습니다.
2. **지점 신고:** 당행 해당 지점에 "착오송금 반환 요청" 접수 (영업일 기준 당일 처리 목표).
3. **수취인 협조 가능 시:** 수취인이 동의하면 즉시 반환 처리.
4. **수취인 거부 시:** 예금보험공사 착오송금 반환지원 제도 안내 (5만 원 이상, 1년 이내).

**소요 시간:** 협조 시 1~3 영업일 / 거부 시 2~4주

---

#### Case B. 당행 → 타행 오류 이체 (다른 은행으로 잘못 보냄)
**처리 가능 여부:** 당행 단독 처리 불가, 수취 은행 협조 필수

1. **즉시 신고:** 고객이 인터넷뱅킹 또는 영업점에서 "착오송금 신고" 접수.
2. **은행 간 협조 요청:** 송금 은행이 수취 은행에 반환 요청 공문 발송.
3. **수취인 연락:** 수취 은행이 수취인에게 반환 의사 확인 연락.
4. **예금보험공사 제도 활용:** 수취인 거부 또는 연락 불가 시 "착오송금 반환지원 서비스" 신청 안내.
   - 신청 기관: 예금보험공사 (kdic.or.kr)
   - 조건: 착오송금액 5만 원 이상, 송금 후 1년 이내
   - 처리 기간: 약 2~4주

**필요 서류:** 이체 확인증, 신분증, 착오송금 경위서(자필 작성)

---

#### Case C. 금액을 더 많이 보낸 경우 (초과 송금)
- 수취인 동의 하에 초과분만 반환 요청 가능.
- 수취인 거부 시 부당이득반환청구 소송 안내 (민사 절차).

---

#### Case D. 본인 다른 계좌로 잘못 보낸 경우
- 동일인 명의 계좌 간 이체이므로 직접 재이체로 해결.
- 단, 압류 계좌로 잘못 이체된 경우 즉시 지점 상담 필요.

---

### 8.2. 고객 응대 핵심 멘트

- **즉시 조치 안내:** "지금 바로 착오송금 신고를 접수해 드리겠습니다. 이체 내역 확인 후 상대 은행에 반환 요청을 진행합니다."
- **시간 관리:** "이체 직후 신고할수록 처리 성공률이 높습니다. 특히 수취인이 출금하기 전에 신고하시는 것이 중요합니다."
- **과도한 보장 금지:** "반환이 반드시 보장되지는 않으며, 수취인의 협조 여부에 따라 달라집니다"라고 정확히 안내하십시오.
- **예보 제도 안내:** "예금보험공사의 착오송금 반환지원 서비스를 이용하시면 법적 절차 없이 반환을 시도해볼 수 있습니다."

### 8.3. 착오송금 반환지원 제도 요약

| 항목 | 내용 |

## 9. 기타 창구 긴급 상황 대응

### 9.1. 보이스피싱 의심 고객 응대
- **징후:** 전화 통화 중 이체 요청, 과도한 긴장감, 타인이 동행하여 이체 지시.
- **즉시 조치:** "잠시 확인이 필요합니다"라며 이체를 보류하고 지점장 또는 감독자에게 즉시 보고.
- **지연 전술:** 신분 확인, 자필 서명 요청 등으로 시간을 확보하십시오.
- **112 신고:** 명백한 피해 상황이면 고객 동의 없이도 경찰 신고 가능.

### 9.2. 인터넷뱅킹 잠금 해제
- **본인 확인 후** 지점에서 해제 가능.
- **필요 서류:** 신분증 (본인 방문 필수).
- **비대면 해제:** 은행 앱 내 본인인증(ARS, OTP) 후 직접 해제 가능 안내.

### 9.3. 통장·카드 분실
- **즉시 조치:** 은행 분실 신고 콜센터 또는 인터넷뱅킹에서 즉시 사용 정지.
- **재발급:** 신분증 지참 후 영업점 방문. 통장 재발급 시 기존 통장 번호 유지 가능.
- **분실 신고 후 거래:** 분실 신고 이후 발생한 부정 거래는 은행이 보상 책임.

## 11. 업무 프로세스 단계별 체크리스트
1. **[인증]** 신분증 확인 및 본인 확인 UI 입력.
2. **[동의]** 필수 약관(개인정보 수집 등) 전체 동의 확인.
3. **[업로드]** PDF 형식의 서류가 누락 없이 올라갔는지 확인.
4. **[상담]** 심사 결과 확인 후 고객에게 금리/한도/상환방식 상세 설명.
5. **[계약]** 고객이 직접 태블릿/PC 화면에서 약관 내용을 끝까지 읽도록 안내.
6. **[실행]** 입금 계좌 유효성 확인 및 최종 실행 후 영수증 전달.
