# platform/frontend

## 역할

창구 직원이 은행 업무(계좌 조회·이체·출금·대출)를 처리하는 Web UI입니다.  
민감정보는 서버에 도달하기 전 브라우저에서 직접 암호화되며, 플랫폼 서버는 원문을 취득할 수 없는 **Zero-Knowledge 구조**를 클라이언트에서 구현합니다.

---

## 기술 스택

| 구분 | 기술 |
|------|------|
| 프레임워크 | React + TypeScript + Vite |
| 라우팅 | React Router DOM v7 |
| 서버 상태 | TanStack Query (비동기 데이터 패칭·폴링) |
| 클라이언트 상태 | Zustand |
| HTTP | Axios |
| 스타일 | Tailwind CSS + shadcn/ui |
| 암호화 | Web Crypto API + `jose` (RSA/AES E2EE) |

### 계좌 조회

https://github.com/user-attachments/assets/8edb3ac9-8ba0-4961-ac56-a27180b782ca


계좌번호를 입력하면 잔액과 거래 내역을 조회합니다.

- **조회 기관**: 드롭다운으로 연결된 은행 기관을 선택
- **기본 조회 기간**: 최근 1달 (오늘 기준 -1개월), 날짜 직접 변경 가능
- **입출금 구분**: 출금(KRW) · 입금(KRW) 컬럼 분리 — 음수(−) 금액은 출금 컬럼에 빨간색, 양수(+) 금액은 입금 컬럼에 초록색으로 표시
- 거래 건별 "입금" / "출금" 배지 자동 표시
- 페이지네이션 지원 (20건/페이지)

### 이체

https://github.com/user-attachments/assets/67e48fdb-0f1e-4501-aa3d-783009f5824c


Step 흐름:
```
수취인 계좌 입력 → 출금 계좌 입력 → 금액 입력 → 최종 확인 + 비밀번호 → (처리 대기) → 결과
```

- **수취인 확인**: 계좌번호 입력 후 포커스 해제 시 자동 조회 — 수취인 이름 즉시 표시
- **금액 입력**: +1만 / +5만 / +10만 / +50만 빠른 추가 버튼, 전액 버튼, 이체 후 예상 잔액 실시간 계산
- **비밀번호**: 핀패드 모달 (4자리, 렌더링마다 숫자 배열 랜덤 셔플)
- **타행 이체 비동기 처리**: 초기 2초 대기 후 3초 간격 폴링, 최대 60초 대기
- **결과**
  - 성공: 거래 상세 (출금·입금 계좌, 거래 일시, 이체 후 잔액) + PDF 영수증 출력
  - 실패: 실패 사유 표시, 출금 계좌 자동 환불 안내
  - 타임아웃: 거래 번호 표시 + 고객센터 문의 안내 (실제 처리 여부 불확실)
- **E2EE**: 계좌번호·비밀번호·주민번호 앞자리 → AES-256-GCM 암호화 후 AES 키를 은행 RSA 공개키로 래핑 (JWE), 이체 금액은 평문 전송

### 출금

Step 흐름:
```
고객 정보 + 계좌 입력 → 잔액 자동 조회 → 금액 입력 → 최종 확인 → 비밀번호 → 결과
```

- **잔액 조회**: 주민번호 앞자리 입력 후 포커스 해제 시 자동 조회 — 사이드 요약 카드에 실시간 표시
- **금액 입력**: +10만 / +50만 / +100만 빠른 추가 버튼, 전액 버튼
- **비밀번호**: 핀패드 모달 (4자리, 렌더링마다 숫자 배열 랜덤 셔플)
- **결과**
  - 성공: 출금 전·후 잔액, 거래 일시 표시 + PDF 영수증 출력

  - 계좌 정지: 해당 은행 문의 안내
  - 시스템 오류: 잠시 후 재시도 안내
- **E2EE**: 계좌번호·비밀번호·주민번호 앞자리 → AES-256-GCM 암호화 후 AES 키를 은행 RSA 공개키로 래핑 (JWE), 출금 금액은 평문 전송

### 대출 신청



https://github.com/user-attachments/assets/eeb1aace-28dd-4856-be3a-fd172db2237f



Step 흐름:
```
서류 제출 → 심사 대기 → 상품 선택 → 계약 서류 확인 → 결과
```

**서류 제출**
- 필수 서류 4종: 신분증 사본 / 재직증명서 / 근로소득 원천징수영수증 / 건강보험료 납부확인서
- PDF만 허용 (매직 바이트 검증), 파일당 최대 10MB
- 서류 파일도 AES-256-GCM으로 암호화하여 전송

**심사 대기**
- SSE(Server-Sent Events)로 심사 결과 실시간 수신
- SSE timeout 시 폴링 fallback — 3초 간격, 최대 5회(≈15초) 재시도
- 심사 결과: 승인(한도·추천 상품) / 거절(사유 표시)

**상품 선택**
- 금리순 / 한도순 정렬 탭
- 대출 금액 입력 (최소 100만 원, 승인 한도 이하), 기간 선택 (12 / 24 / 36개월)
- 월 예상 납입금 실시간 계산 (원리금균등 상환)

**계약 서류 확인**
- 약관 모달 내 끝까지 스크롤해야 동의 버튼 활성화 (강제 열람)
- 비밀번호: 핀패드 모달 (4자리)

**결과**
- 성공: 적용 금리·만기일·월 상환금 표시 + PDF 대출 실행 확인서 출력
- 거절: 거절 사유 표시

- **E2EE**: 고객 정보(주민번호·성명)·계좌 비밀번호·서류 파일 모두 AES-256-GCM 암호화 후 AES 키를 은행 RSA 공개키로 래핑 (JWE)

### 직원 관리 (AGENCY_ADMIN 전용)



https://github.com/user-attachments/assets/744db4ff-f3cb-4ba1-9faf-f5a5b0c3ed8c

- **접근 제어**: JWT `role` 클레임이 `AGENCY_ADMIN`인 경우에만 라우터에서 해당 경로 렌더링
- **직원 목록**: 로그인 ID / 사번 / 소속 대행업체 ID / 권한 / 계정 상태 표시, 페이지네이션 (20명/페이지)
- **직원 상세 패널**: 목록에서 선택 시 우측 패널에 상세 정보 표시 — 비밀번호 초기화 / 계정 삭제 액션 제공
- **직원 등록**: 모달 — 로그인 ID·사번·초기 비밀번호·소속 대행업체 ID 입력, 권한은 `USER`로 고정, 비밀번호는 RSA 암호화하여 전송
- **비밀번호 초기화**: 새 비밀번호 입력 → RSA 암호화 후 `PATCH /admin/employees/{loginId}/password/reset`
- **계정 삭제**: 확인 모달 표시 ("즉시 시스템 접근 차단" 경고) → `DELETE /admin/employees/{loginId}`

## 주요 구현

### 디지털 봉투 암호화 (`useHybridEncrypt`)

금융 트랜잭션 요청 시 브라우저에서 직접 E2EE를 수행합니다.

```
1. 1회용 AES-256 세션 키 로컬 생성 (Web Crypto API)
2. 계좌번호·금액 등 민감 페이로드를 AES 키로 암호화
3. AES 키 + 계좌 비밀번호를 은행 RSA 공개키로 암호화
4. 암호화된 봉투를 플랫폼 서버에 전달
   → 플랫폼은 원문 취득 불가, 은행만 복호화 가능
```

- 은행 RSA 공개키 교체 시 `Key ID`를 명시하여 키 교체 시점 이전 요청도 처리 보장
