# FISAN 기능 명세서

## 1. [프로젝트 A] 중개 플랫폼 (Intermediary Platform)

대행기관 직원용 WEB 서비스 제공, 인증 및 회원관리, 은행 API 중개, AI 업무 보조, 시스템 통합 모니터링 수행
