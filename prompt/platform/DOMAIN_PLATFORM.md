# 은행 대리업 중계 플랫폼

이 플랫폼은 은행에서 제공되는 BaaS 형태의 API를 바탕으로 은행 업무를 대리업체에 제공하는 플랫폼입니다.

## 1. 타겟 사용자

- **은행 대리업 업체** : 은행이 제공하는 업무를 대리해서 수행하는 업체

## 2. 주요 기능

- **은행 업무 중계** : 계좌 조회, 계좌 이체, 예금 출금, 대출 신청 업무를 대리업체에서 수행할 수 있도록 한다.
- **업무 보조 챗봇** : 직원이 업무를 수행함에 있어 불완전 판매를 방지하기 위해 대리업 수행 간 업무를 보조해주는 챗봇을 제공한다.
- **보안과 모니터링** : RSA를 통한 E2EE, mTLS를 활용한 BaaS 연결, JWS 활용 토큰 생성과 같은 보안 기능과 요청/응답 기록 및 에러를 추적할 수 있는 로그 모니터링 시스템을 제공한다.
- **사용자 관리** : 사용자 로그인 및 등록관리를 수행하며, 등록된 사용자만 플랫폼 이용이 가능하다.

## 3. 준수 사항

### 3.1. 보안
- **고객 개인 정보**: DB 내 고객 개인정보 및 금융정보를 절대 평문으로 저장하지 않습니다.
- **True E2EE (디지털 봉투)**: 프론트엔드가 생성한 '1회용 AES 키'로 암호화된 고객 데이터와, '은행의 RSA 공개키'로 잠긴 AES 키를 전달받습니다.
- **Zero-Knowledge (Pass-through)**: 중계 플랫폼은 은행의 개인키가 없어 암호문을 절대 해독할 수 없으며, 원본 그대로 은행 코어에 전달하여 책임 소재를 분리(면책)합니다.
- **인증**: JWT와 Redis를 활용하여 사용자 인증 및 세션을 유지합니다.

### 3.2. 통신
- **mTLS** : 은행에서 제공되는 BaaS API와의 통신을 위해 FAPI 표준인 mTLS를 활용한다.
- **JWS** : API 요청을 전송할 때 JWS를 활용하여 Request Body로 정보를 전달한다.
